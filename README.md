# Faworship Charts

Просмотр и правка чартов в формате ChordPro (`.cho`) в стиле ChartBuilder: транспонирование, capo, слова / аккорды / карта песни, цифры, режим «Сцена», редактор секций и скачивание PDF.

Песни здесь не хранятся: чарт открывается по ссылке — с Google Диска (`https://faworship.github.io/#<название>.<id файла>?key=D`), из GitHub или Dropbox — или файлом с устройства. Сет — тоже ссылка: в ней список песен и тональности, собрать её можно кнопкой «Собрать сет». Настройки, недавние песни и сеты остаются в браузере.

Шрифты в `fonts/` — облегчённые Lato, Carlito и Noto Sans Symbols под лицензией SIL Open Font License 1.1 (тексты лицензий — `fonts/OFL-*.txt`), переименованы в «Faworship Latin / Cyrillic / Symbols».
