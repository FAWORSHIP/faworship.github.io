# Faworship Charts

Бесплатный сайт для чартов песен прославления в открытом формате [ChordPro](https://www.chordpro.org/) (`.cho`): просмотр в любой тональности, редактор, PDF на листах A4, сеты одной ссылкой и библиотека песен из папки Google Диска. Оформление — по образцу ChartBuilder.

**Сайт:** https://faworship.github.io/

Сделан для команды прославления Faworship, но подходит любой группе: песни остаются у группы — на её Google Диске, в GitHub или Dropbox, — а сайт только показывает их по ссылке. Регистрации нет, сервера нет, сайт ничего не хранит.

## Возможности

**Чарт**
- Вид: аккорды и слова, только слова, только аккорды, карта песни.
- Тональность — любая из 12, capo с показом форм аккордов. Тональность можно задать прямо в ссылке.
- Аккорды буквами (C, Am, F), цифрами (1, 6m, 4) или римскими (I, vi, IV). Нотация — H и диезы или B и бемоли.
- Карта песни: значки секций вверху, по нажатию — переход к секции с подсветкой.
- Сжатый вид (повтор секции — только заголовок), MD-пометки, размер текста, светлая и тёмная тема.
- Режим «Сцена»: крупно, тёмная тема, экран не гаснет.
- На широком экране — две колонки секций в рамках, на телефоне — одна.

**Редактор**
- Конструктор: шапка песни, карта (перетаскивание, повторы, пометки), карточки секций 21 типа, палитра аккордов тональности.
- Режим «Текст ChordPro» — для тех, кто пишет руками.
- Проверка ошибок, предпросмотр, отмена и повтор (⌘Z / ⇧⌘Z), черновик сохраняется в браузере.
- «Скачать .cho» и «Ссылка на черновик» — чарт целиком внутри ссылки, чтобы скинуть на проверку.

**PDF**
- Листы A4, одна или две колонки. Секция переносится целиком, а если она выше колонки — делится по строкам с пометкой «продолжение».
- Настройки PDF: вид, тональность, буквы/цифры, нотация, сжатый вид, MD-пометки, карта.
- Файл собирается прямо в браузере, без окна печати, поэтому одинаков в Safari, Chrome и на телефоне и совпадает с превью. На телефоне «Скачать PDF» открывает меню «Поделиться»: «Сохранить в Файлы», Telegram, AirDrop.

**Сеты**
- Сет — это ссылка со списком песен и тональностями. Её можно вставить в график служений или скинуть в чат.
- «Собрать сет»: вставить ссылки на файлы или список песен текстом. Строки вида `1. Стою | G | 148` разбираются сами — можно вставить ячейку из Google Таблицы целиком.
- Песня открывается внутри сета в его тональности. Между песнями — кнопки внизу, свайп на телефоне, ← → на компьютере, список сета из заголовка.
- Песня без чарта остаётся в сете с названием и тональностью.

**Библиотека**
- Библиотека — это ссылка на папку Google Диска. Сайт собирает все `.cho` из неё, из папок внутри и на уровень глубже, например `Песни/Ряды/Ряды.cho`. Новый файл в папке появляется в библиотеке сам.
- Поиск по названию, исполнителю и словам песни. У каждой песни видны тональность, темп и пометка «черновик ИИ».
- Список и копии чартов хранятся на устройстве, поэтому библиотека открывается сразу, в том числе без интернета. Сайт сверяется с Диском, когда библиотеку открывают (не чаще раза в 10 минут) или нажимают «Обновить», и скачивает только новые и изменённые чарты.
- В «Собрать сет» названия из графика сами находят чарты библиотеки. Ниже, в «Выбрать песни», — «Недавние» и библиотеки списком: раскрыть раздел и нажать на песню. Открыт один раздел, у списка своя прокрутка, в большой библиотеке — поиск.

**Ещё**
- «Недавние» и «Сеты» на главной. Недавние песни хранятся с копией текста и открываются без интернета.
- Файл `.cho` можно открыть с устройства или перетащить в окно.
- Когда на сайте выходит новая версия, в открытой вкладке появляется плашка «Вышла версия … — Обновить».

## Как подготовить песню

Чарт — обычный текстовый файл ChordPro. Аккорды пишутся в квадратных скобках перед слогом, секции — блоками, порядок исполнения — строкой `map`:

```
{title: Amazing Grace}
{artist: John Newton, 1779}
{key: G}
{tempo: 72}
{time: 3/4}
{meta: map Intro, Verse 1, Verse 2, Instrumental (MD: только клавиши), Verse 3 x2, Ending}

{start_of_grid: label="Intro"}
| G / / | C / / | G / / | D / / |
{end_of_grid}

{start_of_verse: label="Verse 1"}
{comment: MD: бас — половинными}
A[G]mazing [G7]grace, how [C]sweet the [G]sound
That saved a wretch like [D]me
{end_of_verse}
```

- Названия секций — как в Ableton и ChartBuilder: Intro, Verse 1, Pre-Chorus, Chorus, Bridge, Instrumental, Interlude, Tag, Outro и другие. По названию сайт ставит значок и цвет.
- `x2` в карте — повтор, `(MD: …)` — пометка музыкального руководителя к этому проходу.
- Проигрыши — сеткой тактов (`start_of_grid`), `/` — доля без смены аккорда.
- Необязательно: `{meta: status verified}` (или `draft`, `ai`), `{meta: source …}`, `{meta: original …}`.

Писать файл руками не обязательно: «Новый чарт» на главной собирает его в конструкторе, «Скачать .cho» сохраняет.

## Где хранить песни

| Где | Что сделать | Ссылка |
|---|---|---|
| Google Диск | Загрузить `.cho`, доступ «Все, у кого есть ссылка», скопировать ссылку | `https://faworship.github.io/#<название>.<id файла>?key=D` |
| GitHub | Положить файл в публичный репозиторий, скопировать ссылку на файл | `https://faworship.github.io/#url/<адрес файла>` |
| Dropbox | «Поделиться» → «Копировать ссылку» | то же |
| Устройство | «Открыть файл» на главной | только на этом устройстве |

Любую из этих ссылок можно вставить в поле на главной — сайт сам поймёт, что это. Правку файла на Google Диске загружайте через «Управление версиями → Загрузить новую версию»: адрес файла не меняется, и все ссылки, в том числе в сетах, откроют новую версию. Если удалить файл и загрузить заново, у него будет новый адрес.

**Библиотека.** Положите `.cho` в одну папку Google Диска (можно по папке на песню), откройте доступ «Все, у кого есть ссылка» и вставьте ссылку на папку в поле на главной. Получится `https://faworship.github.io/#lib/<название>.<id папки>` — эту ссылку можно скинуть группе, у каждого откроется весь список.

Кто может открыть песню, решают права доступа к файлу. Слова песен в этом репозитории не хранятся.

## Как собрать сет для графика

1. На главной — «Собрать сет».
2. Вставить список песен (например, ячейку «Song list» из графика) или ссылки на файлы `.cho`. Названия сами найдут свой чарт в библиотеке или среди песен, которые уже открывались на этом устройстве. Или выбрать песни в «Выбрать песни»: «Недавние» и библиотеки списком.
3. Проверить тональности и порядок, дать сету название.
4. «Ссылка на сет» — скопировать и вставить в график.

Состав поменялся — «Изменить» на странице сета, получится новая ссылка. Правки самих чартов видны по старой ссылке.

## Адреса страниц

Всё состояние — в адресе страницы, поэтому любую страницу можно переслать ссылкой.

| Адрес | Что открывает |
|---|---|
| `#<название>.<id>?key=D` | песню с Google Диска в тональности D (`название` — для людей, сайт смотрит на id) |
| `#url/<адрес файла в base64url>?key=D` | файл по ссылке (GitHub, Dropbox) |
| `#t/<сжатый чарт>` | чарт внутри ссылки (черновик) |
| `#set/<песни>?n=Название` | сет; `#set/<песни>/2` — вторая песня сета |
| `#setedit/<песни>` | сборку сета |
| `#lib/<название>.<id папки>` | библиотеку — все `.cho` из папки Google Диска |
| `#edit/<песня>`, `#edit/new` | редактор |
| `#print/<песня>~key=E~view=ly~cols=1` | PDF с настройками |
| `#demo` | пример |

Песни в сете идут через запятую: id файла на Google Диске, `@<адрес файла>` или `!<название>` (песня без чарта; адрес и название — в base64url), после точки — тональность: `#set/1AbC….D,!0KHRgtC-0Y4.G`.

## Как устроен сайт

- Одна страница `index.html`: стили, разметка и скрипт в одном файле, без сборки и без зависимостей. Хостинг — GitHub Pages.
- Google Диск читается через Google Drive API по ключу. Ключ открыт в коде и ограничен: только Drive API и только адрес этого сайта.
- Библиотека обходит папку по уровням. С ключом API Диск отвечает только на запрос по одной папке, поэтому все папки одного уровня спрашиваются одним пакетным запросом (batch, до 100 папок). Папка с 80 песнями — это 3 запроса и около 2 секунд, плюс скачивание новых чартов.
- PDF собирается библиотекой [pdf-lib](https://pdf-lib.js.org/) 1.17.1 и @pdf-lib/fontkit 1.1.1 — они загружаются с CDN, когда открыта страница PDF. Сайт раскладывает секции по листам A4, а при скачивании перерисовывает эти листы в PDF: слова — туда, где их нарисовал браузер, рамки и значки — векторами. В файл встраиваются те же шрифты, что у страницы.
- Настройки, «Библиотеки», «Недавние», «Сеты» и черновики редактора хранятся в `localStorage` этого браузера и никуда не отправляются.
- Сайт не собирает данных: нет аналитики, cookies и входа. Запросы уходят только за файлами песен (Google Drive API или адрес файла) и за pdf-lib. Поисковикам сайт закрыт (`robots.txt`, `noindex`).

## Разработка

```sh
python3 -m http.server 8000   # в папке репозитория
open http://localhost:8000/
```

- С `localhost` файлы с Google Диска не открываются — ключ API ограничен адресом сайта. Для проверки — `#demo`, «Открыть файл» или ссылка на файл в GitHub.
- Настройка — `CONFIG` в начале скрипта: `driveKey` (ключ Google Drive API) и `site` (адрес сайта для ссылок «поделиться»).
- Версия — `VERSION` в начале скрипта: исправление +0.0.1, новая возможность +0.1.0. По ней открытые вкладки узнают о новой версии.
- Регулярные выражения — без lookbehind `(?<!…)`: его не понимают iPhone с iOS ниже 16.4.
- Выкладка — `git push` в `main`, GitHub Pages обновляется примерно за минуту.

**Своя копия сайта** не нужна, чтобы пользоваться: свои файлы на своём Диске открываются и здесь. Если всё же нужна — форк, свой ключ Google Drive API (Google Cloud → включить Drive API → ключ с ограничением на Drive API и адрес вашего сайта, без платёжного аккаунта), вписать его в `CONFIG.driveKey` и включить GitHub Pages.

## Шрифты

`fonts/` — облегчённые до нужных знаков Lato (латиница), Carlito (кириллица) и Noto Sans Symbols (♭ ♮ ♯) под лицензией SIL Open Font License 1.1, тексты лицензий — `fonts/OFL-*.txt`. По условиям OFL изменённые шрифты переименованы в «Faworship Latin / Cyrillic / Symbols».
