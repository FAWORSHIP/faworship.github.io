# Faworship Charts

Просмотр и правка чартов в формате ChordPro (`.cho`) в стиле ChartBuilder: транспонирование, capo, слова / аккорды / карта песни, цифры, режим «Сцена», редактор секций и PDF.

Песни здесь не хранятся: чарт открывается с Google Диска по ссылке `https://faworship.github.io/#<название>.<id файла>?key=D` или файлом с устройства. Настройки и недавние песни остаются в браузере.
